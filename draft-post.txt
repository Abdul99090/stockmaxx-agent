1/ Built StockMaxx Agent for @buildonbase Stocks Maxxing (Agentic Stock Finance): an AI agent that scans tokenized stocks on Base, scores momentum behind a NAV-staleness guard, and runs a paper portfolio on Base Sepolia inside hard risk caps. Demo 👇
2/ How it works: read tokenized-stock data via the Base Tokenized Stocks API (multiplier + Chainlink NAV), score momentum/consistency, then let a hard risk guard veto or approve every order — 20% per position, 60% max exposure, stop-loss & take-profit.
3/ Every paper trade is written to an intent ledger anchored to the live Base Sepolia block it was decided at. Positions are tracked in share-equivalents (balanceOfUI style). Mainnet execution exists only as a disabled stub — a human decides if it ever turns on.
4/ Code + full demo transcript: https://github.com/Abdul99090/stockmaxx-agent — built in the open during Stocks Maxxing season. Testnet by design: the Quest rules say testnet submissions are not judged less favorably. Not financial advice.
